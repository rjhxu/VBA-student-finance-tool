# Student Finance Tracker

This was a student project I made for the MSE100 course at the University of Waterloo. Messing around with VBA in excel was pretty fun. There are some basic budgeting tools and some macros for you to use.

---

## What’s in here?

* **UserForms for Data Entry:** I built custom pop-up menus so I can just type in an expense, pick a category, and hit "Add." It keeps the raw data clean and prevents me from accidentally deleting formulas.
* **VBA Automation:** There's a decent amount of logic running in the background to handle the sorting and calculations. It automatically moves new transactions into the right tables and keeps everything organized.
* **Live Dashboards:** I linked the data to dynamic charts. As soon as I add an expense, the spending-vs-budget visuals update so I can see exactly where my money is going.
* **Structured Tables:** Everything is stored in Excel Tables, which makes it easy to filter by month or category if I need to look back at something specific.

---

## How to use it

1. **Enable Macros:** Since this uses VBA, you have to hit "Enable Content" at the top when you open the file, or the forms won't launch.
2. **Launch the Form:** Click the "Add Transaction" button on the main sheet to bring up the entry menu.
3. **Check the Stats:** Head over to the dashboard tab to see the visual breakdown of your spending habits.
